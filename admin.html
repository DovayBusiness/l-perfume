WhatsApp Ordering (Critical)

Format: Use international format without + or spaces. Example: 2348012345678 for +234 801 234 5678. This number receives all order messages.

How WhatsApp Ordering Works

1. Customer clicks "Order on WhatsApp" on any product.

2. Modal collects quantity, name, phone, delivery location.

3. Pre-filled message opens in WhatsApp:

Hello, I would like to order:
Product: [Name]
Brand: [Brand]
Size: [Size]
Quantity: [Qty]
Price: ₦[Price]
Customer name: [Name]
Delivery location: [Location]
